Mac-zu-Handy P2P Tunnel (Mobile Inferenz)

Zero Cloud Cost

Große LLMs (z. B. 27B / 70B) passen aufgrund von Smartphone-RAM-Limits nicht direkt in den mobilen Webbrowser. Über einen verschlüsselten P2P-Tunnel nutzt Ihr Smartphone die Apple Silicon Metal GPU Ihres Macs von unterwegs:

1 Auf dem Mac MLX-Server starten: 

python -m mlx_lm.server --model /Users/umurey/LocalModels/Qwen3.8-27B-Uncensored-MLX/4-bit --port 8000

2 Kostenlosen Tunnel starten (Cloudflare / Tailscale): 

cloudflared tunnel --url http://localhost:8000

3 Generierte URL am Handy in das Feld oben einfügen:

z. B. https://my-mac.trycloudflare.com/v1

Für leichtgewichtigere mobile Inferenz direkt im mobilen Safari/Chrome-Browser können Sie oben auch einfach auf „⚡ In-Browser WebGPU“ schalten.
