    On-device workspace

    Private · on this device

    Files are parsed, split into chunks and indexed with BM25 in a background worker on this device, and kept in this browser's storage unless you choose memory only. Nothing is uploaded or synced.       Answer receipt

      A receipt lists the excerpts this answer cited, with a SHA-256 fingerprint of each file and the exact position of each passage. Anyone who has the same files can check that every excerpt is an exact, unchanged passage.

      What it proves

      Each workspace excerpt is an exact, unchanged passage of the file with the recorded fingerprint, at the recorded position, and belongs to this receipt through its Merkle proof. The source check can be recomputed from it.

      What it does not prove

      Who wrote the answer: a signature only shows the receipt is unchanged since a key signed it, and whose key that is only a public key from the signer shows. Nor which excerpts the model actually read, that the answer is correct, or anything about knowledge-base excerpts.

      The file is created on this device and contains excerpts of your documents and fingerprints that identify them. It only leaves this device if you share it.

      Verify a receipt

      Choose a receipt and the original files. Both are read on this device; files are matched by their fingerprint, not by their name.
